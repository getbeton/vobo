# Security

## Report a vulnerability

Do not open a public issue for a security problem.

1. Go to the [Security tab](https://github.com/getbeton/vobo/security) of this repository.
2. Click **Report a vulnerability**.
3. Give the steps to reproduce the problem and what an attacker can get.

We tell you when the fix is live.

## Scope

- The code and the files in this repository.
- The hosted service at `vobo.dev`.
